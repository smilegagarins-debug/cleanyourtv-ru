# ТВ и точка - программа проверки и чистки телевизора

Файлы релизов для https://cleanyourtv.ru. Устанавливать удобнее командой с сайта: она скачивает программу отсюда или с другого зеркала и сверяет контрольную сумму (SHA-256).

- macOS и Linux: `curl -fsSL https://cleanyourtv.ru/i | sh`
- Windows: `irm https://cleanyourtv.ru/i.ps1 | iex`

Программа находит Android-телевизор в домашней сети, определяет модель и выключает рекламу и слежку по проверенным спискам, только с вашего согласия. Ничего не удаляет; «Вернуть как было» восстанавливает всё.

Списки для моделей основаны на открытом проекте [Gathin23/cleanyourtv](https://github.com/Gathin23/cleanyourtv) (MIT).
